# Contributing

1. Open an issue first for bigger changes.
2. `python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt`, then `.venv/bin/python -m pytest -q` before every commit.
3. English code, comments, docs and commit messages. Plugin protocol: [PLUGINS.md](https://github.com/nxtsound/nxtsound-server/blob/main/PLUGINS.md).
4. Open a pull request; CI runs the tests.
